WavKAN-CL is a structurally interpretable arrhythmia detection framework that replaces black-box neural network layers with learnable Mexican Hat wavelets on Kolmogorov-Arnold Network edges. Using curriculum learning for class imbalance, it achieves 0.88 ventricular recall with only 95,189 parameters and sub-millisecond CPU inference, enabling real-time deployment on battery-powered wearable devices.
