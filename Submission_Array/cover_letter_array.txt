Dear Dr Aswal,

Thank you for the opportunity to revise our manuscript, originally titled "WavKAN-CL: An Interpretable and Parameter-Efficient Curriculum Learning Framework for Inter-Patient Arrhythmia Detection". We submit the revised version, now titled "Wavelet Kolmogorov-Arnold Networks for Inter-Patient ECG Heartbeat Classification: A Controlled Multi-Seed Evaluation".

The reviewers identified real errors, and we agree with all of their major points. Reviewer #3 suggested that the work would be publishable as a negative result if the title, abstract and highlights were reframed. We followed that suggestion and rewrote the manuscript as a controlled evaluation. The main changes are:

1. Claims withdrawn. The interpretability claim, the reduced generalisation gap, the benefit of the curriculum, and suitability for real-time or wearable use are removed. Where a claim could be tested, it is now tested and reported whatever the outcome.
2. One protocol for every comparison. The evaluated model and four baselines are trained with the same data, split, inputs, optimiser, budget, checkpoint rule and 20 seeds. They are compared with seed-paired Wilcoxon tests, Holm-Bonferroni correction, effect sizes and confidence intervals. The result is parity: no statistically detectable Macro-F1 difference.
3. Every number re-derived. A verification script released with the code recomputes every reported number from the per-seed result files. This resolves the inconsistencies Reviewer #3 listed.
4. Methods matched to the code. This includes the interval features, which use two following intervals; the task is therefore described as offline. The ablation of interval positions is now labelled correctly.
5. The interpretability premise tested. Null models show that the trained wavelet parameters do not support a physiological reading. The analysis is stated to be at the parameter level only.
6. Records 201 and 202. These come from the same subject, as Reviewer #4 noted. The overlap is now stated, and removing record 202 leaves the comparison unchanged.
7. Novelty stated precisely. We claim no new KAN formulation or training algorithm. The contribution is the controlled evaluation.
8. The evaluated configuration and its selection history. The reported configuration is the one a validation-based rule selects. The rule was applied after the test-set results of all configurations had been seen, and the manuscript discloses this.

The submission includes:
- a point-by-point response to every reviewer and editor comment;
- the revised manuscript (clean version);
- a highlighted version comparing it with the original submission;
- a graphical abstract;
- five highlights.

The manuscript contains data availability, code availability, CRediT, competing interest, funding, ethics and generative-AI statements. The author list is unchanged.

The public code repository cited under Code availability also contains the manuscript source, so a similarity report may match it.

This manuscript is original, has not been published, and is not under consideration elsewhere. Both authors approved the revision. The authors declare no competing interests.
