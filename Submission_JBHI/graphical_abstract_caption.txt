Overview of the WavKAN-CL arrhythmia detection pipeline. Raw ECG signals from the MIT-BIH database undergo beat segmentation, followed by dual-branch feature extraction using learnable Mexican Hat Wavelet Kolmogorov-Arnold Network layers and RR-interval temporal analysis. Features are fused via curriculum learning to classify heartbeats into four AAMI classes. The framework achieves 0.88 ventricular recall with only 95,189 parameters, enabling edge deployment.
